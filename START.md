# BLOCKWAVE — как запустить разработку (для Кирилла)

## ⚡ Ленивый режим (рекомендуется): делегируй сетап целиком

Шаги 1–3 ниже можно НЕ делать руками. Достаточно: установить Claude Code (code.claude.com/docs), распаковать этот пакет в папку, открыть в ней терминал один раз, запустить `claude` и вставить:

> Прочитай START.md, CLAUDE.md и docs/. Выполни за меня шаги 1–3 из START.md сам: проверь и доустанови зависимости (xcode-select, brew, cmake, git, gh), сделай git init и первый коммит, создай публичный репозиторий на GitHub через gh и запушь. Затем автономно выполни Phase 0 и Phase 1 из docs/ROADMAP.md, делегируя субагентам из .claude/agents/. Работай до Definition of Done, спрашивай меня только когда нужен пароль, клик авторизации или вкусовое решение. По завершении — CHECKPOINTS/PHASE-1.md и стоп.

Чтобы не кликать разрешения на каждый чих: на первые запросы жми «allow always», либо запускай `claude --permission-mode acceptEdits`. Есть и режим полного автопилота без вопросов (`--dangerously-skip-permissions`) — работает, но включай его только в папке проекта и понимай, что агент тогда ничего не переспрашивает.

Рабочее название проекта: **BLOCKWAVE** (поменять = одна замена по файлам, скажи архитектору).
Вся разработка делегирована: **Claude (приложение) = архитектор/продюсер**, **Claude Code = исполнитель** с 4 субагентами. Твоя роль: запускать фазы, проверять чекпоинты, слушать пресеты.

## Шаг 1. Поставить окружение (один раз, ~20 минут)

macOS. В Терминале:

```bash
xcode-select --install          # компилятор Apple, бесплатно
# если нет Homebrew: /bin/bash -c "$(curl -fsSL https://brew.sh/install.sh)" — точную команду смотри на brew.sh
brew install cmake git
```

Claude Code (если ещё не стоит) — ставь по официальным докам: https://code.claude.com/docs
Проверка: `claude --version`, `git --version`, `cmake --version`.

FL Studio (маковский) понадобится только на фазах QA.

**Windows-версия без Windows:** репозиторий публикуем на GitHub (публичный, мы же GPL) — GitHub Actions бесплатно собирает Windows VST3 и гоняет pluginval на облачных Windows-машинах при каждом пуше. Живой тест винды позже сделают бета-тестеры. Тебе Windows не нужен вообще.

## Шаг 2. Развернуть проект

Распакуй этот пакет в папку, например `~/dev/blockwave/`, зайди в неё и:

```bash
git init
git add -A
git commit -m "kickoff: specs, roadmap, agents"
```

Потом создай пустой публичный репозиторий на GitHub и запушь (Claude Code поможет командами, просто попроси).

## Шаг 3. Запустить первую автономную сессию

В папке проекта запусти `claude` и отправь ровно это:

> Прочитай CLAUDE.md и все файлы в docs/. Затем автономно выполни Phase 0 и Phase 1 из docs/ROADMAP.md. Делегируй работу субагентам из .claude/agents/ по их специализации. Работай до полного выполнения Definition of Done каждой фазы, не останавливайся на полпути. По завершении создай CHECKPOINTS/PHASE-1.md по протоколу из ROADMAP и остановись для ревью.

Советы по режиму:
- На запросы разрешений для сборки/тестов жми «allow always» — или запускай `claude --permission-mode acceptEdits`, чтобы правки файлов не требовали подтверждений.
- Долгую фазу можно отправить работать, а самому заниматься своими делами — вернёшься к готовому чекпоинту.

## Шаг 4. Протокол чекпоинтов (твои ~15 минут на фазу)

Когда Claude Code остановился на чекпоинте:
1. Открой `CHECKPOINTS/PHASE-N.md` — там отчёт: что сделано, логи pluginval, пути к артефактам, открытые вопросы.
2. Скопируй содержимое чекпоинта (и вопросы) архитектору — в наш чат в приложении Claude. Архитектор ревьюит, отвечает на вопросы и даёт команду на следующую фазу.
3. Отправь эту команду в Claude Code. Повторить.

## Шаг 5. Твои особые точки участия

- **Phase 3 (UI):** посмотреть скриншоты, дать вкусовые правки по пиксель-арту.
- **Phase 6 (пресеты):** отслушать отрендеренные wav-кандидаты (папкой, быстро) и отрезать до 128.
- **Phase 7 (QA):** прогнать чек-лист в FL Studio (готовый список действий будет в чекпоинте).
- **Phase 8 (лонч):** сделать демо-бит на синте — ты умеешь, это лучший маркетинг.

## Правила безопасности проекта

- Никаких ассетов, текстур, шрифтов и названий из Minecraft/Mojang. Только оригинальный пиксель-арт и обычные английские слова. Это записано в CLAUDE.md, агенты обязаны соблюдать.
- Лицензия: GPLv3, копирайт твой. Открытый код = бесплатный JUCE, доверие комьюнити и пиар; при желании позже можно сменить модель, т.к. права на код у тебя.
