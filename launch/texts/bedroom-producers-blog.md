**Subject:** BLOCKWAVE — free open-source synth, square waves only, patches built from blocks

Hi Tomislav,

I released a free synthesizer called BLOCKWAVE and thought it might be a fit for the free plugin coverage.

The premise is a constraint: it has exactly one waveform, the square. Two pulse oscillators with independent pulse width and hard sync, a square sub, NES-style LFSR noise, and a RAW switch that turns the anti-aliasing off when you want the dirt. That covers more ground than it sounds like — the 128 factory presets run from NES leads to PWM pads to cave drones.

The part that makes it different from other free synths: **you build patches by placing blocks on a 3×3 grid.** A base archetype in the middle, material blocks around it — ICE, LAVA, OBSIDIAN, VOLT and ten more — and the synth computes the patch. It is deterministic, so the same blocks always make the same sound on any machine, and every factory preset shows the grid that made it, so the browser teaches the system while you audition. Sixteen exact block patterns are secret recipes that unlock hand-tuned sounds; three are published, the other thirteen are unlisted for people to find.

Details: VST3 + AU + standalone on macOS (10.15+, Intel and Apple Silicon), VST3 on Windows 10/11. GPLv3, source on GitHub. No account, no email gate, no paid tier. The builds are not code-signed — there is a one-line quarantine command in the readme and on the site.
